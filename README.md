### ⚡ Current Engineering Focus

I am currently building a rigorous foundation in computer science and systems engineering, focusing on writing verifiable, zero-leak C code and mathematical logic:

* **Imperative Computation (C99):** Contract-based programming (`@requires`, `@ensures`, `@loop_invariant`), strict pointer semantics, and manual memory management verified via `Valgrind`.
