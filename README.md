##  Detailed Engineering Roadmap

<br>

<details>
<summary><b>🟢 Level 1: C Fundamentals & Memory Management <code>[Completed ]</code></b></summary>
<br>

- **1.1 Basics:** C Program Structure, Data Types, Bitwise & Logical Operators, I/O (`printf`/`scanf`).
- **1.2 Compilation:** Toolchain (`gcc`), Compile vs Run, Debugging Basics.
- **1.3 Control Flow:** `if-else`, `switch`, `while`, `do-while`, `for` loops.
- **1.4 Functions:** Scope, Declarations, Parameters, Return Values.
- **1.5 Arrays & Strings:** 1D/2D Arrays, Null Terminator, String functions (`strlen`, `strcpy`, `strcmp`).
- **1.6 Basic Data Structures:** Stack & Queue implementations using Arrays.
- **1.7 Memory Core:** Memory Layout (Stack vs Heap), Memory Addresses (`&`).
- **1.8 Pointers:** Pointer Arithmetic (`*`), Pass by Reference, Dynamic Memory Allocation (`malloc`, `realloc`, `free`).
- **1.9 Linked Lists:** Nodes, Traversal, Search, Insertion & Deletion (Singly & Doubly Linked Lists).
- **1.10 Structs & File I/O:** Struct Definition, Array of Structs, File Pointers, Reading/Writing Files.
- **1.11 Algorithms:** Linear & Binary Search, Bubble & Selection Sort, Big O Basics.
- **1.12 Applied Concepts:** Command Line Arguments (`argc`, `argv`), Input Validation, Memory Leaks, Buffer Overflows.
- **1.13 Architecture Extensions:** `Makefiles`, Function Pointers, `Unions` & `Enums`, Bit-fields, Preprocessor (`#define`), Modular Architecture (`.h` / `.c`).
</details>

<br>

<details>
<summary><b> Level 2: Mathematical Foundations & Algorithmic Logic <code>[In Progress ]</code></b></summary>
<br>

- **2.1 Digital Logic:** Boolean Algebra, Truth Tables, Bitwise Manipulation.
- **2.2 Complexity Analysis:** Big O, Big Omega, Big Theta, Time & Space Complexity.
- **2.3 Number Theory:** Prime Numbers, GCD (Euclidean Algorithm), Modular Arithmetic.
- **2.4 Combinatorics & Sets:** Set Theory, Permutations, Combinations.
- **2.5 Graph Theory Basics:** Nodes, Edges, Directed/Undirected Graphs, Adjacency Matrix/List.
- **2.6 Probability & Statistics:** Conditional Probability, Randomness, Entropy.
- **2.7 Linear Algebra:** Vectors, Matrix Operations, Matrix Multiplication.
- **2.8 Advanced Paradigms:** Greedy, Divide & Conquer, Dynamic Programming, Backtracking.
</details>

<summary><b> Level 4: Architecture & x86-64 Assembly <code>[Planned ]</code></b></summary>

- x86-64 Registers (RAX, RBX, RSP, RBP, RIP), RFLAGS, Addressing Modes.

- Low-Level Debugging with `GDB`, Shellcoding & Position Independent Code (PIC).
